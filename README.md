# Voe F5 Tour

Landing page para apresentação de uma marca/proposta de turismo, com foco em experiência visual, responsividade e conversão.

## Tecnologias identificadas
- HTML
- Tailwind CSS
- Swiper
- JavaScript
- Plus Jakarta Sans

## Recursos
- Layout responsivo
- Carrosséis
- Identidade visual personalizada
- Seções comerciais
- Adaptação para dispositivos móveis

## Objetivo
Apresentar uma solução digital de turismo com interface moderna e foco na experiência do usuário.
